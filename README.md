# MyBible / 多版本圣经阅读器

A simple mobile-first Bible reader with multi-version comparison, audio reading, and search.

一个以手机优先的多版本圣经阅读器，支持对照阅读、朗读播放与搜索功能。

---

## Features / 功能特点

- 📖 Multi-version Bible comparison  
  多版本圣经对照阅读
- 🔊 Audio playback with highlighting  
  朗读播放，并高亮当前经文
- 🔍 Search by book, chapter, or keyword  
  按书卷、章节或关键词搜索
- 📜 Genealogy support (planned)  
  族谱功能（计划中）
- 🇨🇳 CN：思高圣经（SBV / Studium Biblicum Version）
- 🌍 EN：NRSVCE（New Revised Standard Version, Catholic Edition）
